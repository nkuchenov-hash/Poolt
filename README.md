# Poolt

Universal remote control for TVs and other devices.

Current MVP foundation:
- Android / Kotlin / Jetpack Compose
- generic device and command model
- pluggable protocol drivers
- discovery flow
- remote-control UI
- demo driver for hardware-independent testing

Planned drivers:
1. Samsung Smart TV
2. LG webOS
3. Android TV / Google TV
4. Roku
5. Infrared devices through supported Android hardware or an external IR bridge

Open the repository in Android Studio, sync Gradle and run the app on Android 8.0 or newer.
